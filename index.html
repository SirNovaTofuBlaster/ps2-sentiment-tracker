How to use

You don't need a token: without one, Save changes walks you through saving on GitHub in a few clicks. A token makes saving one click. If the repository is yours, use a fine-grained token for just this repository with Contents set to read and write (add Actions for Run scraper now). A collaborator on someone else's repository needs a classic token with the public_repo scope; that scope covers all your public repositories, so give it a short expiry (it can't start the scraper by hand, which saving does anyway). Tick Remember only on your own computer: it keeps the token for this whole github.io site. Step-by-step: How to use → Token. The token is only sent to api.github.com, and commits use your GitHub no-reply email.
